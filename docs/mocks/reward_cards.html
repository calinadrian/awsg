Chest rewards

Food catalog

Five types, one slot each, so you always carry at most five foods. Each type has three builds with real trade-offs, and each build is a ladder of five ranks: 75 foods. Every slot starts at Common, and your first pick sets its build. After that a chest only offers the next rank of that food, so numbers only go up, all the way to Legendary. The values shown are your total at that rank, and they are sample numbers.

Read it top to bottom

Icon and name first, then what the spell does, then its numbers, then what it costs you. Each section sits at the same height on every card, and every card is one size, tall enough for the longest spell text in the game. You compare across instead of hunting, and a reroll never moves the buttons under your cursor. Rarity decoration stays around the content, so the numbers read the same on every card.

Rarity is a ladder

Each step keeps what is below it and adds one thing. Common is plain steel. Uncommon tints the frame and top. Rare adds a glow and corner brackets. Epic adds gems, a filled rarity tag, a light behind the icon and a slow pulse. Legendary adds a gold double frame, a beam, drifting embers, a light sweep and a flash when dealt.

Upgrades show their gain

A new spell shows plain values. An upgrade shows old value, arrow, new value in green, using the same comparison rows the game already computes. Spell slots become six pips, with the slot this card would take in burgundy. Chests offer food instead of rings and amulets, so run rewards never compete with the gear your character wears. You carry 5 foods, one of each type, and each climbs from Common to Legendary, as listed in the catalog above. Numbers only go up, and no food gives move speed.

Quieter controls

"Banish (1 left)" no longer repeats three times: each card has a plain Banish button and the shared count sits once in the action bar. Reroll and Skip carry their key and their value. Banish stays a separate control below the card, so it can never pick the card by accident.
